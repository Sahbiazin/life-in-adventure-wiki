# Conteúdo do repositório privado

Destino: [Sahbiazin/life-in-adventure-wiki](https://github.com/Sahbiazin/life-in-adventure-wiki), criado com visibilidade privada.

O repositório reúne o projeto completo: aplicativo HTML, scripts, documentação, testes, mapas gerados, bases de dados e arquivos originais da extração da versão 1.2.47.

Arquivos binários e arquivos de grande porte usam Git LFS. Ao clonar, instale Git LFS e execute:

```powershell
git lfs install
git lfs pull
```

O aplicativo está em `web/life-in-adventure/dist/index.html`. Os mapas começam em `mapas/1.2.47/pt/index.md`.

Ambientes virtuais, caches, ferramentas externas baixadas e pacotes temporários de publicação do Sites não fazem parte do repositório. As fontes do aplicativo são incluídas como arquivos normais, sem depender do repositório privado interno do Sites.

Os dados extraídos pertencem ao jogo original. O repositório deve permanecer privado; a publicação no GitHub não altera a audiência do aplicativo hospedado.
